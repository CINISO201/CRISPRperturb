# 🔬 CRISPRperturb

**R package for comprehensive Perturb-seq analysis and quality control**

## Features
- ✅ validate_knockdown() - Statistically validate gRNA knockdown efficiency
- ✅ detect_isoform_switch() - Find genes that switch isoform usage
- ✅ generate_perturbseq_report() - Create comprehensive QC reports
- ✅ Interactive Shiny Dashboard - Point-and-click interface

## Key Results
- **Best knockdown:** KDM1A (97.5% reduction, Log2FC = -5.30)
- **Isoform switching detected:** PTPRC, CD3G

## Installation
```r
devtools::install_github("CINISO201/CRISPRperturb")
```
